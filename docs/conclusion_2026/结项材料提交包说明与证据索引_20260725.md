## 2. 当前结项口径（建议答辩使用）

- 项目成果已达到“大创原型可演示、可验收”的核心目标：完成 FastAPI 后端、React 前端、Dify 工作流接入、本地知识检索、安全规则快答、引用展示、反馈记录、运行监测和知识库态势展示。
- 知识资产应表述为：**3009 条结构化知识片段，采用 29 列统一字段，来自 400+ 权威来源；不是 3009 份独立文档。**
- 来源字段完整性可以表述为：`source_title/source_org/source_url/references` 均已全量补齐；716 个唯一来源 URL 已完成自动化访问审计。
- 链接可访问性必须如实表述为：352 个当前自动化实测可打开，333 个被站点策略或反爬阻断，31 个当前网络错误。被阻断不等于死链，需要人工抽检或官方镜像复核。
- 本地备份必须如实表述为：173 个 URL 有本地原件或官方镜像归档证据；151 个 PDF 来源中，111 个已有本地 PDF 原件，仍缺 40 个 PDF 原件（原因逐条记录，属站点 CDN/WAF 拦截或已改为 HTML 网页，非死链）。
- 回答效果可以表述为：自动回归与本地规则链路已通过现有测试；有效回答率最终应以独立专家按统一量表评分为准，不把自动关键词命中率等同于专家准确率。
- 7×24 三个月试运行必须表述为：自 2026-07-01 起真实累积；完整三个月周期最早于 2026-10-01 形成，不倒填历史数据。

### 必须由负责人/学院完成

1. 在结题报告“经费使用情况”中填写实际到账、实际支出、结余、票据/报销情况，并与学校财务系统一致。

3. 完成负责人签字、指导教师/所在单位意见、实验室与设备管理部门盖章等线下流程。
4. 若学校要求完整三个月试运行证明，应在 2026-10-01 后导出完整周期运行报告；若当前阶段提交，只能提交阶段性运行证据。

### 建议项目组继续补强

1. 继续按影响片段数优先补齐剩余 40 个缺失本地 PDF 原件（多数需换网络环境/校园网/VPN 或官方站内搜索人工下载，以绕过 CDN/WAF 拦截），并记录 SHA-256、获取时间、最终 URL、内容类型与文件大小。
2. 对 31 个网络错误逐条人工复核；如果原链接迁移，替换为同机构新链接或官方镜像。
3. 对 333 个被站点阻断来源做分层抽检，保存浏览器访问截图或可复核归档。
4. 将高风险/应急类知识条目标记为优先人审对象，逐步提高 `reviewed` 比例。
5. 答辩前在配置 `DIFY_APP_API_KEY` 的环境中补一次 Dify SSE 首事件、完整回答耗时和引用命中截图。
