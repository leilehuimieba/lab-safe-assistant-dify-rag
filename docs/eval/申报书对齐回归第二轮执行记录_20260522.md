## 1. 本轮目标

第二轮不是简单再跑一次回归，而是围绕用户明确指定的三条主线做实修：

1. `need_more_info`：该补充信息的问题必须稳定进入澄清链；
2. 多轮：低风险追问不能再无意义掉回慢链路；
3. 性能：在不越安全边界的前提下，把申报书对齐回归的整体耗时压到可交付水平。

## 2. 本轮核心改动

### 2.1 `need_more_info` 统一澄清分流

涉及文件：

- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/services/answer_service.py`
- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/services/kb_service.py`
- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/routers/chat_routes.py`

关键动作：

1. `ask_for_more_info` 不再复用应急模板，而是输出专门的补充信息提示；
2. 新增 `should_force_more_info()`，对以下场景强制澄清：
   - 模糊对象：`这个试剂`、`这个柜子`、`这个能不能放`
   - 条件不足：`过夜反应晚上可以回家吗`
   - 替代方案类：`最适合替代二氯甲烷的安全溶剂`
3. 将 `need_more_info` 的期望 lane 统一收紧到 `rule-engine`，避免评测口径与实际模型字段错位。

### 2.2 低风险多轮快答放开

涉及文件：

- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/services/fast_path_service.py`
- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/routers/chat_routes.py`

关键动作：

1. 取消“只要有历史就禁止快答”的一刀切策略；
2. 增加历史域识别：`_history_domains()`；
3. 增加多轮放行判断：`_allow_fast_path_with_history()`；
4. 对离心机、标签、储存等低风险追问允许沿历史域继续走本地快答；
5. 对起火、泄漏、受伤、爆炸、报警等明显应急词继续禁止历史快答，强制保留到规则 / 上游链。

### 2.3 本地快答覆盖面扩充

涉及文件：

- `D:/newwork/lab-safe-assistant-dify-rag/web_demo/services/fast_path_service.py`

新增 / 补强域：

1. `配酸稀释`
2. `访客准入`
3. `安全培训准入`
4. `风险评估`
5. `离心机基础`（补强“震动 / 振动 / 异响 / 停机”等追问词）
6. `化学品储存`（补强混放 / 同柜识别，并对特定不相容问题做保守降级）

补强点：

1. 引入 domain required markers，减少“关键词撞车”造成的误命中；
2. 调整本地快答评分，使“标题/问题直接相关”的条目优先于泛化推荐条目；
3. 对“硝酸 + 乙醇 + 同柜”这类具体不相容问题，禁止误走错误快答。

### 2.5 评测口径同步更新

涉及文件：

- `D:/newwork/lab-safe-assistant-dify-rag/artifacts/eval/申报书对齐回归集_v2.csv`

更新原因：

1. 第二轮之后，若干标准化低风险题已被**有意**收敛到 `local-fast-path`；
2. `need_more_info` 在返回结果中的真实 lane 是 `rule-engine`，不应继续写成 `need_more_info`；

因此，本轮同步更新了对应题目的：

- `expected_lane`
- `should_use_fast_path`
- `should_use_cache`
