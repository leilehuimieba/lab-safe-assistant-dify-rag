## 2. 本轮已落地的运行证据骨架

### 2.1 快照记录脚本

文件：`scripts/record_runtime_snapshot.py`

每执行一次，会采集：

1. `/health`
2. `/api/meta`
3. `/api/stats`
4. 本地 `runtime.json`
5. Dify 可达性与当前运行态关键字段

输出：

- `artifacts/runtime/health_snapshots.jsonl`
- `artifacts/runtime/health_snapshots.csv`

### 2.2 汇总脚本

文件：`scripts/build_runtime_report.py`

基于快照 CSV 自动生成：

- `artifacts/runtime/reports/runtime_latest_summary.md`
- `artifacts/runtime/reports/runtime_latest_summary.csv`

可后续扩展为：

- `runtime_week1_summary.md`
- `runtime_2026W22_summary.md`
- `runtime_month1_summary.md`

### 2.3 一键执行脚本

文件：`scripts/run_runtime_check_once.ps1`

用途：

- 一次命令完成“采一次快照 + 生成一份最新摘要”；
- 适合后续接入 Windows 任务计划或手工日检。

### 2.4 第四轮新增：任务计划固定流程

第四轮已经补齐以下脚本：

- `scripts/register_daily_runtime_check.ps1`
  - 注册 Windows 任务计划；
- `scripts/show_daily_runtime_check.ps1`
  - 查看任务状态、下次执行时间和完整参数；
- `scripts/unregister_daily_runtime_check.ps1`
  - 卸载任务计划。

当前已实际注册的任务：

- 任务名：`LabSafeAssistant-DailyRuntimeCheck`
- 计划频率：每日 `08:30`
- 下次执行时间：`2026-05-23 08:30`
- 日志文件：`artifacts/runtime/logs/daily_runtime_check.log`

## 4. 建议执行频率

### 4.1 每日

至少执行一次：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_runtime_check_once.ps1
```

如需注册为长期自动执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\register_daily_runtime_check.ps1 -RunTime 08:30
```

查看状态：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\show_daily_runtime_check.ps1
```

如需卸载：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\unregister_daily_runtime_check.ps1
```

目标：

1. 留下最基础的 uptime / health / dify 可达记录；
2. 形成可累计的连续时间证据。

### 4.2 每周

建议每周固定一次：

1. 跑一遍申报书对齐回归；
2. 生成一份本周 `runtime_weekX_summary.md`；
3. 记录本周故障、性能波动、知识库变更和修复动作。

### 4.3 每月

至少形成一份试运行小结，内容包括：

1. 本月健康快照数；
2. `/health` 正常率；
3. Dify 可达率；
4. 平均耗时 / P95 / 最大耗时；
5. 本月新增问题；
6. 已处理动作；
7. 下月优化计划。
