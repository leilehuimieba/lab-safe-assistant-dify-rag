### 4.2 新增每周一键脚本

文件：

- `scripts/build_weekly_runtime_report.ps1`

用途：

1. 先补一条最新快照；
2. 再按周生成 `runtime_<ISO周>_summary.*`；
3. 同时生成 `weekly_issues_<ISO周>.md`。

用法：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_weekly_runtime_report.ps1 -BaseUrl http://127.0.0.1:8091 -IsoWeek 2026W21
```
