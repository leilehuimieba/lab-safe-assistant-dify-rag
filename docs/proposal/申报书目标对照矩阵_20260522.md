## 当前执行顺序结论

从矩阵看，后续必须坚持：

1. **先处理 P0：准确率与评测体系**
2. **再处理 P1：检索 / 多轮 / 动态更新 / 性能**
3. **最后持续积累 P2：7×24 与试运行证据**

也就是说，后续每轮新增改动都必须能回答：

> 这项改动到底是在缩小哪一条申报书差距？

如果回答不了，就不应该优先做。
