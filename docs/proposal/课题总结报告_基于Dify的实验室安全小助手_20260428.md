## 一、项目概述

本项目围绕高校实验室安全知识查询效率低、资料分散、学生对安全规范理解不一致以及高风险问题回答不可控等问题，基于 Dify 平台搭建 RAG 增强的大语言模型实验室安全小助手系统。系统通过结构化知识库、Dify 工作流、本地安全规则和 Web 演示页面，为实验室人员提供实验室安全知识查询、规范操作提醒、引用依据展示和应急类问题保守引导。

项目当前定位为标准课题版原型系统，聚焦 Dify/RAG 问答主链路，不扩展为完整实验室安全闭环管理平台。培训考核、管理看板、事故复盘、多模态识别和生产级部署等内容作为后续拓展方向。

## 二、主要建设内容

### 1. 知识库建设

项目已整理形成实验室安全本地知识库和 Dify 导入包：

- 本地知识库：`knowledge_base_curated.csv`；
- Dify 导入包：`release_exports/v8.2/knowledge_base_import_ready.csv`；
- 评测问题集：`eval_set_v1.csv`。

知识库字段覆盖标题、类别、子类、风险等级、典型问题、标准回答、操作步骤、PPE、禁止事项、应急处置、来源标题、来源机构、来源链接和标签等内容，便于后续导入 Dify Dataset 并持续扩充。

### 2. Dify RAG 问答链路

项目通过 `.env.dify_rag` 配置 Dify 地址、App Key 和超时时间，通过 `web_demo/services/upstream_service.py` 调用 Dify `/v1/chat-messages` 接口，并解析 SSE 流式响应。当前系统已验证能够调用 Dify 工作流，20 题正式评测中有 14 题返回 `model=dify-workflow`。

### 3. 本地 Web 演示系统

项目基于 FastAPI 构建本地演示服务，主要接口包括：

| 接口 | 作用 |
|---|---|
| `/` | Web 问答页面 |
| `/health` | 健康检查 |
| `/api/meta` | 系统元信息 |
| `/api/search` | 本地知识库检索 |
| `/api/chat` | 实验室安全问答 |
| `/v1/parameters`、`/v1/chat-messages` | Dify 代理接口 |

当前服务运行地址为：`http://127.0.0.1:8091`。

### 4. 安全规则约束

项目使用 `safety_rules.yaml` 维护高风险问题规则。对于危险操作、违规处置和应急事故类问题，系统会在调用 Dify 前进行规则匹配。若命中终止类规则，则直接返回规则回答或应急引导，避免模型输出不安全建议。

当前 20 题正式评测中，有 6 题由 `rule-engine` 处理，其中包括禁止类问题和应急类问题。
